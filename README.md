# Calculateur de moyenne

Projet réalisé par Jeanne Imhoff dans le cadre du cours Culture Numérique 3 (EPF, 2026-2027).

## Contexte
Ce projet sert de support pour apprendre à utiliser Git et GitHub afin de sauvegarder, organiser et suivre l'évolution d'un programme tout au long de son développement.

## Objectifs
- Pratiquer la gestion de versions avec Git (add, commit, push)
- Suivre l'évolution d'un projet AlgoBox sur GitHub
- Publier une version figée du projet (tag v1.0)

## Fonctionnalités réalisées
- Saisie du nombre de notes
- Saisie des notes une par une
- Calcul et affichage de la moyenne
- Affichage du résultat : "Admis" si la moyenne est supérieure ou égale à 10, sinon "Non admis"

## Technologies utilisées
- AlgoBox 1.2.0
- Git
- GitHub

## Comment ouvrir et exécuter le programme
1. Installer AlgoBox : https://www.xm1math.net/algobox/
2. Télécharger ou cloner ce dépôt
3. Ouvrir AlgoBox, cliquer sur **Ouvrir** et choisir le fichier `src/moyenne.alg`
4. Cliquer sur **Tester Algorithme**, puis sur **Lancer Algorithme**
5. Entrer le nombre de notes, puis chaque note
